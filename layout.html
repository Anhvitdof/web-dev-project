Structuring a Clean Layout

Before writing CSS, it helps to break a page down into clear structural sections using semantic HTML tags.

Basic Page Sections

  • Header & Nav: Stays at the top of every page in the exact same order so visitors never get lost.
  • Main Content: Holds the primary headings, paragraphs, tables, or cards for that specific page.
  • Footer: Sits at the bottom with copyright details or extra reference links.

Why Use External CSS?

Linking one style.css file to all five HTML pages means you only have to update colors or fonts in one place instead of editing every file separately.
