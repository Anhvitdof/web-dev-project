Core Web Design Topics

Key concepts that keep informational pages readable, structured, and easy to use on any device.

Key Standards & Rules

Topic Target Standard Purpose
Body Text Size 16px minimum Keeps paragraphs comfortable to read without zooming.
Line Height 1.5 or higher Separates lines of text so blocks feel less crowded.
Color Contrast 4.5:1 ratio Ensures text stays clear against light or dark backgrounds.
Tap & Click Targets 46px height on mobile Helps users select links and buttons accurately on touchscreens.

What To Check Next

Image Box

Before wrapping up a page, do a quick pass over your structure and interactive elements so nothing is missed.

  • Check navigation links across every page
  • Test form labels and input validation
  • Verify external links open cleanly
