Web Accessibility Basics

Following Web Content Accessibility Guidelines (WCAG) helps people who use screen readers, keyboard navigation, or zoomed-in text.

Quick Accessibility Checklist

  • Always write descriptive alt text on images so screen readers can explain what is shown.
  • Use proper heading order (h1 first, then h2, then h3) instead of skipping levels.
  • Attach clear <label> tags to every input box on a form.
  • Make sure every link and button can be reached using only the Tab key on a keyboard.
